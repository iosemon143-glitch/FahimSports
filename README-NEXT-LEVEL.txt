NEXT LEVEL Android App

This project packages the original React/Vite premium sports-store UI inside Android using WebViewAssetLoader.
The web UI is built first, then copied into app/src/main/assets/web and packaged into the APK.
GitHub Actions workflow: .github/workflows/build-apk.yml

Admin Panel / live product management is a separate Phase 2 feature and is not yet connected to a backend.


FIXES v2: corrected branding, WhatsApp external navigation, bundled image paths, and Android WebView performance.
